# ATmega32 Memory

Tags: memory, flash, sram, eeprom, atmega32

The ATmega32 has three main memory spaces, all of which are linear and regular:

1. **Program Memory (Flash):** 32 KB of [[In-System Reprogrammable Flash Memory]] where the program code is stored.
    
2. **Data Memory (SRAM):** 2 KB of internal [[Data SRAM]] for storing data and variables during runtime.
    
3. **EEPROM Memory:** 1024 bytes of [[EEPROM Data Memory]] for non-volatile data storage.
