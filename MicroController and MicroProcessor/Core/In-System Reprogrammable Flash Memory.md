# In-System Reprogrammable Flash Memory

Tags: flash, memory, program_storage

The ATmega32 contains 32 KB of on-chip Flash memory for program storage.

- Since most AVR instructions are 16 bits wide, the Flash memory is organized as 16K x 16.
    
- It has an endurance of at least 10,000 write/erase cycles.
    
- The Flash memory space is divided into two sections: the Application Program Section and the Boot Program Section.
