# General Purpose Register File

Tags: #registers, #alu, #atmega32, #cpu

The [[ATmega32 Architecture|ATmega32]] has 32 general-purpose 8-bit working registers (R0-R31).

- All registers are directly connected to the Arithmetic Logic Unit (ALU).
    
- This architecture allows two independent registers to be accessed in a single clock cycle.
    
- The ALU can take two 8-bit operands and produce one 8-bit result in one cycle.
