# Core Components of a Computer System

**Tags:** #computer_architecture #cpu #memory #io #bus

At its most fundamental level, a computer system is composed of four essential components that work together to execute programs. The way these components are interconnected defines the computer's architecture.

### 1. The Central Processing Unit (CPU)

The CPU, or microprocessor, is the brain of the computer. It is responsible for fetching instructions from memory, decoding them, and then executing them. All the computation and decision-making happens inside the CPU. For a detailed look at its internal parts, see [[The Central Processing Unit (CPU) Explained]].

### 2. Memory (Primary/Main Memory)

Memory is what separates a computer from a simple calculator. It is a temporary storage area for both program instructions and the data those instructions operate on.

- **Instructions:** Coded information that directs the CPU's activities.
    
- **Data:** Coded information that is processed by the CPU. Every program and all the data it needs must be loaded into memory before the CPU can access it. See [[Computer Memory Fundamentals]] for more.
    

### 3. Input/Output (I/O) Devices

I/O devices are the computer's interface to the outside world.

- **Input Ports/Devices:** Allow the computer to receive information from users and external equipment. Examples include keyboards, mice, and sensors.
    
- **Output Ports/Devices:** Allow the computer to communicate the results of its processing. Examples include monitors, printers, and storage devices like hard disks.
    

### 4. The System Bus

In modern computers, the CPU, Memory, and I/O devices don't have individual dedicated connections to each other. Instead, they communicate over a shared set of electrical pathways called a **bus**. This is a more efficient and scalable design. Think of it as a highway that all components use to send and receive information. For a deeper dive, see [[The System Bus]].

This bus-centric architecture is the standard for virtually all computers today.
