# ATmega32 I/O Ports

**Tags:** #microcontroller #atmega32 #ports

The ATmega32 has 40 pins in total. Most of these pins are for general-purpose I/O, organized into four 8-bit ports:

* **PORTA**
* **PORTB**
* **PORTC**
* **PORTD**

Each of the 32 I/O pins is **bidirectional**, meaning it can be configured as either an input or an output pin.
