### ✅ Page 3: "What is a file system?"

This page explains what a **file system** is inside an OS.

---

### 🔥 Definition

A **file system** is a method used by the operating system to **store, organize, and manage files on disk** so that they **remain accessible and not lost** even after turning off the computer.

It's not just a folder explorer—it's a **complete architecture**.

---

### ✅ Role of the File System

|Feature|Meaning|
|---|---|
|Data organization|Keeps files in directories|
|Efficiency|Stores and retrieves files fast|
|Persistence|Keeps files even after reboot (non-volatile storage)|
|Management|Tracks used/free disk space|
|Protection|Controls who can access files|

---

### ✅ Examples

Different OSes use different **file systems**:

|File System|Used In|
|---|---|
|**FAT32, exFAT**|USB drives, SD cards|
|**NTFS**|Windows|
|**EXT3/EXT4**|Linux|
|**APFS**|macOS, iOS|

---

### ✅ Simple analogy

Think of your hard disk/SSD like a **library**:

- Books = files
    
- Book ID = inode number
    
- Bookshelves = disk blocks
    
- Librarian = file system
    
- Book index = directories
    

---

### ✅ Why needed? (Key exam line)

A file system provides **abstractions** and **structures** so users can store and retrieve **data efficiently and safely**.
