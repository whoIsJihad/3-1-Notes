This collection of notes covers the fundamental mechanisms and abstractions that an operating system provides for managing memory. We will explore how the OS creates an isolated virtual address space for each process, the APIs programmers use to interact with this memory, and the underlying hardware and OS strategies, like segmentation, used to implement this virtualization.

The goal is to move beyond the basic concept of an address space and understand the practical API calls, common programming errors, and the mechanics of address translation.
