# Types of Games

Games can be categorized based on two key axes:

1. **Information:**
    
    - **Perfect Information:** All players know the complete state of the game (e.g., Chess).
        
    - **Imperfect Information:** Players have incomplete information (e.g., Poker, Scrabble).
        
2. **Determinism:**
    
    - **Deterministic:** No element of chance. The outcome of an action is fully determined (e.g., Chess).
        
    - **Chance (Stochastic):** Involves random elements, like dice (e.g., Backgammon, Monopoly).
