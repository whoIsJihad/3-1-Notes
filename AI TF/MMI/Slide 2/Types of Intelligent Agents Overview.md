# Types of Intelligent Agents Overview

There are five basic types of intelligent agents, ordered by increasing generality and complexity:

1. [[Simple Reflex Agents (Table-Driven and Simple Reflex)]]
    
2.  [[Model-based reflex agents (Adds internal memory (state)) ]]
    
3. [[Goal-Based Agents]] (Considers the future)
    
4. [[Utility-Based Agents]] (Maximizes "happiness" or success metric)
5. [[ Learning agents (Applies to all types)]]
