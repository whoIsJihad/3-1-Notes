
## 🎯 Goal First, Then Problem

The requirement that **problem formulation must follow goal formulation** is a matter of logical necessity in designing any rational agent.

Here is the concise explanation:

1. ### **Goal Formulation: Defining the Destination**
    
    The goal defines **what** the agent is trying to achieve. It is the desired state of the world that the agent wants to reach. * _Analogy:_ You decide you want to be at the **BUET CSE Graduation Ceremony** (the goal state).
    
2. ### **Problem Formulation: Defining the Route**
    
    The problem formulation defines **how** to achieve that goal. It requires identifying the initial state, the available actions (operators), and the path cost. If you don't know where you are going, you can't figure out the steps to get there.
    

|**Step**|**Why It Must Be Done in Order**|
|---|---|
|**Goal $\rightarrow$ Problem**|**Goal Formulation** provides the crucial **target state** that the **Problem Formulation** needs to define its search space.|
|**Without a Goal?**|The agent has no objective measure of success. It cannot determine which actions are relevant or what the "solution path" should look like. An agent without a goal is just wandering—a tourist, not a problem-solver!|

In short: **You cannot define the path (the problem) until you have specified the destination (the goal).** The goal state acts as the **terminal condition** for the search algorithm, which is the whole point of the problem formulation!
