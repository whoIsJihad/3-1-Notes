## I. Description of the Simulated Annealing Algorithm

Simulated Annealing (SA) is a probabilistic metaheuristic search method used to find the global optimum of an objective function. It is inspired by the annealing process in metallurgy, where a material is slowly cooled to reach a state of minimum energy.

The algorithm works as follows:

1. **Initial State and Temperature (**$T$**):** The process begins at an initial solution ($\mathbf{x}_0$) and a high initial "temperature" ($T_0$).
    
2. **Neighbor Generation:** In each step, a random neighbor ($\tilde{\mathbf{x}}$) of the current solution ($\mathbf{x}$) is generated.
    
3. **Metropolis Criterion:** The core decision-making rule determines whether to accept the neighbor.
    
    - **Improvement (**$\Delta E \le 0$**):** If the new solution is better (lower cost/energy), it is always accepted.
        
    - **Worsening (**$\Delta E > 0$**):** If the new solution is worse (higher cost/energy), it is accepted based on a probability $p = \exp(-\Delta E/T)$.
        
4. **Cooling Schedule:** The temperature ($T$) is gradually lowered over time (e.g., $T \leftarrow T_0/(k+1)$). This controls the search, shifting it from broad, random exploration (high $T$) to focused, greedy exploitation (low $T$).

## III. How Simulated Annealing Avoids Local Optima

A standard **greedy search algorithm** will stop the moment all immediately reachable neighbors are worse than the current state (i.e., it hits a local optimum). It never moves to a worse state to see if there's a better path beyond.

Simulated Annealing avoids this trap using the **Metropolis Criterion** (Lines 8, 10-12), which enables it to accept moves that _increase_ the cost ($\Delta E > 0$).

1. **High Temperature (Exploration):** When $T$ is high (start of the algorithm), the denominator in the exponent is large, making the term $\exp(-\Delta E/T)$ close to 1. This results in a high probability ($p$) of accepting even _very bad_ moves. This randomness allows the agent to jump over barriers and escape local optima early in the search.
    
2. **Low Temperature (Exploitation):** As $T$ decreases (Line 17), the term $\exp(-\Delta E/T)$ becomes very small for large positive $\Delta E$. This means the probability ($p$) of accepting a bad move drops exponentially. The algorithm becomes nearly identical to a greedy search, focusing on fine-tuning the best solution found so far.
    

By **starting with high randomness** to explore and **gradually reducing that randomness** to converge, SA ensures it does not get permanently stuck in the first local minimum it encounters, greatly increasing its chance of finding the true **global optimum**.
